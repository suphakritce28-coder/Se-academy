SE Academy — Interactive Structural Engineering Textbook (PWA v0.3)

เวอร์ชันนี้ดัดแปลงจาก SE_Academy_Web_App_v0.2.zip โดยคงบท 1.1 และเนื้อหาต้นฉบับไว้
สารบัญ: 5 Parts / 35 Chapters
เนื้อหาที่พร้อมอ่าน: บท 1.1 (7 หัวข้อ) พร้อมแบบฝึกหัด 5 ข้อ, Interactive Lab และเครื่องคำนวณสองสมาชิกขนาน
อีก 34 บทแสดงสถานะรอจัดทำเนื้อหาตามต้นฉบับ ไม่ได้สร้างเนื้อหาหรือเฉลยขึ้นมาเอง

เผยแพร่แบบง่ายด้วย Netlify Drop:
1. ไปที่ https://app.netlify.com/drop ผ่านคอมพิวเตอร์
2. ลากไฟล์ SE_Academy_PWA_v0.3_Deploy.zip ลงในพื้นที่รับไฟล์ หรือนำโฟลเดอร์ที่แตก ZIP แล้วไปวาง
3. Netlify จะออก HTTPS URL ลงท้าย .netlify.app ให้คุณ (ควร Claim site เพื่อคงการเผยแพร่ระยะยาว)
4. เปิด URL บนมือถือเพื่อใช้งาน; กด 'เพิ่มแอปลงหน้าจอหลัก' แล้วทำตามคำแนะนำของอุปกรณ์

เผยแพร่ผ่าน Vercel:
- นำโฟลเดอร์ทั้งหมด (index.html, manifest.webmanifest, sw.js, icons/, vercel.json) ไป deploy เป็น Static Site
- คุณสามารถใช้ Vercel CLI จากโฟลเดอร์นี้ด้วย 'vercel deploy --prod' หลังเข้าสู่ระบบ

หมายเหตุสำคัญ:
- สำหรับ PWA และ Offline ต้องเปิดผ่าน HTTPS และเข้าเว็บไซต์ออนไลน์อย่างน้อยครั้งแรกเพื่อให้ Service Worker แคชไฟล์
- เนื้อหาที่แคชไว้เปิดอ่านออฟไลน์ได้โดยไม่ต้องใช้ AI; การเปิด ChatGPT และการดาวน์โหลดไฟล์บางกรณีต้องใช้อินเทอร์เน็ต
- ความก้าวหน้าและคำตอบ Quiz เก็บใน localStorage บนอุปกรณ์และเบราว์เซอร์ที่ใช้งาน
- กด 'สำรองข้อมูล' เพื่อส่งออก JSON และกด 'กู้คืนข้อมูล' เพื่อนำเข้าบนอีกเครื่อง; ยังไม่มีการ Sync ระหว่างอุปกรณ์อัตโนมัติ
- ปุ่ม ChatGPT เปิดเว็บไซต์ภายนอกพร้อมเตรียมคำถาม; แอปไม่มี AI API และไม่มีการส่งคำถามอัตโนมัติ
- สูตรเครื่องคำนวณ: delta=P/(k1+k2), P1=k1*delta, P2=k2*delta; P [kN], k [kN/mm], delta [mm]
- เนื้อหาวิชาการบท 1.1 อ้างอิงตามรายการหนังสือที่ปรากฏในแต่ละหัวข้อของต้นฉบับ
